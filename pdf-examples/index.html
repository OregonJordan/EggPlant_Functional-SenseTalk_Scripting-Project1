EggPlant_Functional‑SenseTalk_Scripting‑Project
EggPlant Functional is a black‑box GUI test automation tool developed by TestPlant. Its approach uses image‑matching technology rather than object‑level inspection of the application being tested. This enables system‑wide automation of a system‑under‑test instead of an application‑specific solution. It also means that the technology used to build the application under test does not matter, nor does the system it runs on. EggPlant utilizes a high‑level, object‑oriented scripting language called SenseTalk.
